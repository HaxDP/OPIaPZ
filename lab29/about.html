Про цей сайт

Сайт зроблений як приклад простої HTML та CSS сторінки. Основна ідея була не робити щось складне, а нормально показати структуру документа.

Що я використав

  1. семантичні теги header, main, section, footer
  2. окремий CSS файл для стилів
  3. flexbox для розміщення блоків
  4. media query для мобільної версії

Також на сторінках є активне посилання меню, щоб було видно на якій сторінці знаходиться користувач.
