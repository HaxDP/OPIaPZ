# Лабораторна робота 26

## Тема
Використання інструментів для аналізу та оптимізації коду.

## Що реалізовано
У проєкті реалізовано програму для обчислення суми квадратів від 1 до n двома підходами, базовим ітеративним алгоритмом та оптимізованим алгоритмом на основі аналітичної формули. Програма порівнює продуктивність за часом виконання і використанням пам'яті, виконує профілювання через `cProfile` і додатково перевіряє коректність результатів для кількох сценаріїв.

## SOLID у рішенні
Принцип SRP дотримано через поділ на окремі класи для обчислення, профілювання, перевірки, форматування звіту та виводу. Принцип OCP реалізовано через можливість додати новий алгоритм, імплементувавши контракт `SequenceAnalyzer`, без змін у сервісі порівняння. Принцип LSP забезпечено взаємозамінністю реалізацій аналізаторів. Принцип ISP підтримано через невеликі протоколи `SequenceAnalyzer` і `ResourceProfiler`, які не містять зайвих методів. Принцип DIP виконано тим, що `BenchmarkService` залежить від абстракцій, а не від конкретних класів.

## Використані інструменти аналізу та оптимізації
Для аналізу та оптимізації використано `cProfile` для визначення вузьких місць за часом виконання та `tracemalloc` для фіксації пікового споживання пам'яті. Ефективність оцінюється на однакових сценаріях для базового та оптимізованого алгоритмів.

## Очікуваний результат
Для кожного сценарію відображаються результат обчислень, час виконання, процесорний час, пікове використання пам'яті та зріз профайлера. Наприкінці виводиться перевірка коректності, яка підтверджує збіг результатів обох алгоритмів.
